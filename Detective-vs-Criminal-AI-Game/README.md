# 🎮 Detective vs Criminal – AI Strategy Game

An interactive Python-based strategy game where the player controls a detective and competes against an AI-controlled criminal.

The criminal uses **Minimax Algorithm with Alpha-Beta Pruning** to make strategic decisions and find escape routes.

## 🚀 Features

- Interactive 8×8 game board.
- AI-controlled criminal opponent.
- Minimax decision-making algorithm.
- Alpha-Beta Pruning for search optimization.
- Heuristic-based move evaluation.
- Detective special powers:
  - Freeze – Skip the criminal's next turn.
  - Teleport – Move near the criminal.
  - Trap – Temporarily block a strategic tile.
- Multiple escape points and obstacles.
- Animated victory and defeat screens.
- Restart functionality.

## 💻 Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/seran4595/Detective-vs-Criminal-AI-Game.git
```

**2. Open the project directory**

```bash
cd Detective-vs-Criminal-AI-Game
```

**3. Run the game**

```bash
python src/detective_vs_criminal.py
```

## 🎯 Objective

Control the detective, catch the criminal and prevent it from reaching an escape point. The AI criminal uses strategic search to avoid capture and escape.
